## 安全与公开仓库检查

- 仓库未跟踪 APK、AAB、签名密钥、`local.properties`、`.env` 或本机缓存目录。
- 未发现私钥、GitHub token、Google API key、OpenAI key 或本机微信临时路径。
- Manifest 只声明 `android.permission.INTERNET`，并保持 `allowBackup=false`、`usesCleartextTraffic=false`。
- 第三方彩报图片不会提交到 Git 或打包进 APK；运行时下载内容仅保存在应用私有目录。

## 尚未关闭的正式发布门禁

1. 当前 APK 使用 debug 证书，不能作为长期生产升级身份；后续正式发行必须配置并长期保管生产签名。
2. V0.1.0 使用过一次性本地验收签名，本轮未证明其可直接覆盖升级到 V1.2.0；需要时应先卸载旧包再安装测试版。
3. 当前只有 API 26/API 37 模拟器证据，尚未完成物理真机验收。
4. 第三方彩报完整图片的公开展示授权尚未记录为已确认，因此 GitHub Release 保持草稿状态，不作为公开正式发行。
