## 本次交付

- 合并未单独发布的 V1.3 和值 `0—27` 完整走势、落点连线、遗漏和四行统计。
- 首页试机号跨日保留至次日北京时间 `16:30`；到点后当日新号写入前显示 `---`。
- 走势图期号并入统一横向 viewport；彩报标题、相邻换期与双边界禁用状态完成。
- 首页只保留期号作为开奖详情入口；日期仅作不可点击元数据。
- 新增独立云南省开奖公告：销售额、中奖总额、奖池资金余额、兑奖截止日、三玩法中奖/派奖信息。
- 公告通过 Room v5→v7 非破坏性迁移保存；写入和读取均与本地开奖号按期号、日期、三位号码对齐。
- 自动与手动同步统一按“开奖号→云南公告”串行执行；云南 JSON 请求拒绝重定向，并限制单个响应不超过 `2 MiB`。
- 修复开奖详情深色模式内容色不可读问题，并更新五入口设备主流程的过期首页断言。

## 代码质量评审

评审覆盖正确性、可读性、架构、安全和性能。发布前发现的 Required 问题均已处理：

1. 云南官方适配器原先会跟随重定向并无响应体上限；已补失败测试并改为拒绝重定向、限制 `2 MiB`。
2. `V1MainFlowTest` 仍依赖旧首页语义；已改为稳定测试标签与首页选中语义。
3. 开奖详情深色模式部分文字继承黑色；已改用 Material 3 `onBackground`、`primary` 和 `onPrimaryContainer` 语义色，并用当前 APK 复核。
4. 公开文档中的个人绝对路径已改为 `%USERPROFILE%` 或可移植字体声明。

评审结论：源码与草稿测试版可提交；生产正式发行仍被下方门禁阻止。

## Git 与 GitHub

- 远端仓库：`https://github.com/ikaros0202/lucky3D`，默认分支 `main`。
- `main` 包含本次源码、测试、Room schema、规格、原型和发布文档；APK/AAB 不进入 Git 历史。
- `v1.4.0` Draft Release 指向本次发布提交并附带上述 debug 测试 APK。
- 历史 `v1.2.0` Draft Release 保留，不删除或改写历史资产。

回滚时优先撤销本次发布提交；数据库迁移为非破坏性，旧版安装包不应在未验证降级策略时覆盖安装到 schema v7 数据库。GitHub Release 保持草稿，因此可先移除或替换草稿资产而不向公众发布。

## 尚未关闭的正式发行门禁

1. 当前 APK 使用 Android debug 证书，不能建立长期升级身份；正式发行必须配置并安全保管生产签名。
2. 本轮完整设备回归来自 API 37 模拟器；历史 V1.4 行为另有 API 26 模拟器证据，但尚无物理真机验收。
3. 第三方彩报完整图片的公开展示授权仍未记录为已确认；Release 因此保持 Draft。
4. 选号与彩报任务仍缺最终独立设计图验收，不能宣称整个 UI 里程碑全部关闭。
5. lint 保留 108 条非阻断警告；其中 98 条是历史/兼容资源，删除前需单独确认，不在本次发布中静默清理。
6. 仓库未声明开源许可证；公开可见不等同于授权他人复制、修改或再分发。
