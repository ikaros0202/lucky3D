# 首页期号入口与云南省奖情查询规格

> 日期：2026-08-12
> 状态：原型、实现、数据/迁移测试、API 37 设备测试与深浅色复核已完成；正式生产发行门禁另行关闭
> 适用平台：Android 手机，Jetpack Compose + Material 3

## 1. 决策背景

用户进入首页通常直接关注某一期。旧版首页同时暴露期号和日期入口，查询页又混合最近期数、年份和日期范围，造成多个竞争入口。本规格将首页与查询页收敛为期号唯一入口：期号负责导航，日期仅作为开奖结果的元数据；同时把已批准原型中的完整云南省奖情内联到查询页。

## 2. 范围与不变边界

- 页面标题固定为“开奖查询”。
- 页面只暴露一个期号选择入口；日期以次级元数据显示，不是按钮、筛选器或独立查询模式；不在 UI 中显示最近期数、年份、开始/结束日期或对应按钮。
- 保留 `DrawQuery.Issue`、`DrawQuery.Year`、`DrawQuery.Recent` 及兼容导航参数，供既有调用和迁移使用，但当前 UI 只暴露期号入口。
- Room 仍是开奖记录唯一事实来源；页面只能展示已校验并写入本地的数据。
- 开奖号码同步与云南省开奖公告分开存储和校验；不以其他地区或全国奖情填充云南公告。
- 实现前批准的原型位于 `docs/prototypes/2026-08-12-yunnan-announcement/`，本规格只同步其行为契约，不把原型截图当作实现证据。

## 3. 期号入口与查询行为

### 3.1 默认状态

从首页点击期号进入页面后默认选中该期号并立即展示本地已确认记录。期号选择器按有效期号倒序列出候选；每个候选行显示期号、三位开奖号和开奖日期，但日期不可单独点击。

### 3.2 Issue selector

- 使用 Material 3 菜单、底部选择面板或等价 Compose 选择器承载期号列表，遵循确认/取消和返回模型。
- 期号是唯一选择值；列表按有效期号倒序排列，单行触控区域至少 `48dp`。日期、开奖号和勾选态是该行的辅助信息。
- 确认期号后立即执行 `DrawQuery.Issue(issue)` 或等价的本地期号查询；不得把日期转换成新的查询入口。
- 取消、返回或点击面板外部不会改变当前查询；没有可用期号时显示明确空态和恢复入口。

### 3.3 页面顺序

选定期号有记录时按以下顺序在页面内展示：

1. 期号入口；
2. 开奖结果：期号、开奖日期和三位开奖号；
3. 云南省开奖公告：销售额、中奖总额、奖池资金余额、公告期号、开奖日期；销售额、中奖总额和奖池资金余额同属金额摘要，兑奖截止日作为独立日期字段（来源提供时）；
4. 玩法奖情：单选、组选3、组选6各自的中奖注数和单注奖金，顺序固定为单选→组三→组六；
5. 可选派奖：只展示正数玩法的派奖注数与单注金额，顺序固定为单选→组三→组六；
6. 数据分析：和值、和尾、跨度、奇偶/大小/质合、012 路、组选形态、连号和两码关系。

不再通过底部弹层承载主要单期详情。若后续增加链接跳转，不能以其他地区或第三方内容补全云南奖情。

## 4. 云南省开奖公告口径

云南省开奖公告是按期号关联的独立奖情记录，必须先通过结构、期号、日期、金额和玩法字段校验后写入 Room。本轮只展示：

- 销售额（界面标签固定为“销售额”）、中奖总额和奖池资金余额；奖池余额来源固定为云南接口 `prizeLog.nextAmount`，领域与 Room 单位为分（`Long`），输入必须非负且最多两位小数，官方真实 `0` 与旧库 `null` 区分；
- 公告期号、开奖日期；兑奖截止日独立保存和展示（来源提供且通过校验时），不得从金额字段推断；
- 单选、组选3、组选6各自的中奖注数与单注奖金；不得出现“基础中奖”可见分组标题；
- 可选动态派奖玩法、注数与单注金额，仅保留正数玩法并按单选→组三→组六排序。

首页公告标题和查询页章节标题固定为“云南省开奖公告”。奖池资金余额只在开奖详情页展示，不在首页摘要展示。不得从其他地区或全国奖情、第三方文章、空响应或异常载荷推断中奖注数、奖金、奖池余额或公告正文，也不得用来源/地域前缀改写“销售额”。列表与详情中的奖池值或其他公告字段不一致、非法、缺失时，整条公告不得写入 Room。

公告只能与所选期号的开奖结果按期号、开奖日期和三位开奖号精确配对；首页只有三项均与最新开奖号一致时展示摘要。跨期或被官方修正后失配的旧公告不得与最新开奖号拼接，任一项不一致时保留公告缺失/不可用状态。

派奖显示规则：只要至少一个玩法的派奖注数和单注金额均为正数，显示整行 `【派奖】`；若没有正数派奖，整行不存在。玩法行和派奖行都按单选→组三→组六稳定排序。

## 5. 状态与错误

- 加载：保留期号入口和稳定结果区域，不用全屏 spinner 替换页面。
- 有记录：按第 3.3 节顺序展示结果、云南省开奖公告、玩法奖情、派奖（如有）和分析。
- 无记录：显示“该期没有开奖记录”和包含所选期号的说明，保留期号入口以便修改；不显示空的公告或分析卡片。
- 公告缺失：保留开奖结果，公告区显示明确缺失/不可用状态，不以其他来源补齐；旧期公告不得借用来填充当前期。
- 离线：只显示本地已确认记录；本地没有所选期号时使用明确无记录空态，不把网络失败包装成正式开奖结果。

## 6. 验收标准

- 首页只有期号可点击，日期仅作元数据；查询页没有日期选择器、最近期数、年份或日期范围入口。
- 期号选择器按有效期号倒序展示，确认后 repository 收到单期期号查询，页面按本地 Flow 更新；所有选择器和返回/取消操作触控目标至少 `48dp`。
- 有记录时结果、云南省开奖公告、玩法奖情、可选派奖和数据分析按顺序内联；详情金额摘要同时展示销售额、中奖总额和奖池资金余额，兑奖截止日独立；标题和金额文案准确为“云南省开奖公告”“销售额”，首页不显示奖池余额。
- 单选、组选3、组选6中奖注数与单注奖金均保留且无“基础中奖”标题；存在正数派奖时显示一行 `【派奖】` 并按单选→组三→组六排序，无派奖时整行不存在。
- 奖池 `nextAmount` 非负且最多两位小数并按分保存；真实零值 `0L` 与旧库 `null` 可区分；列表/详情不一致或非法/缺失时整条拒绝，不跨期拼接公告和开奖号。
- 云南公告缺失、非法期号、无记录和离线状态均有明确状态，不回退到其他地区奖情。
- 单元测试覆盖期号默认选择、期号切换、公告字段校验（含 `prizeLog.nextAmount`）、列表/详情一致性、玩法排序和派奖显隐；Compose UI 测试覆盖有记录、无记录、奖情缺失、期号选择器、首页不显示奖池和两种派奖状态。测试是否通过由实施阶段记录。
