# Lucky3D 静态彩报页设计

> 状态：产品负责人已批准方案二
> 日期：2026-07-28
> 适用范围：Android V1

## 1. 目标

为喜欢浏览彩报的用户保留一个明确入口，同时在真实彩报来源、授权和更新机制尚未确定时，不引入不可靠内容或新的后台依赖。

## 2. 信息架构

底部导航由四项调整为五项，顺序为：

```text
首页　走势　选号　方案　彩报
```

彩报是独立一级页面。切换到其他入口再返回时保持原页面状态。五项均使用文字标签和可辨识图标，触控目标不小于 `48dp`。

## 3. 页面内容

彩报页按以下优先级排列：

1. 顶部标题“彩报”。
2. 常驻说明“当前为静态示意内容，不会自动更新”。
3. 随安装包内置的报纸占位图，可随页面纵向滚动查看。
4. 图片来源与许可说明。
5. “理性购彩，量力而行”提示。

图片采用 Swello 发布于 Unsplash 的报纸照片，依据 Unsplash License 免费使用：

- 页面：https://unsplash.com/photos/Us9-XfhoVjA
- 作者：Swello
- 用途：仅作为彩报页面的静态开发占位图，不表示图片内容是福彩分析。

## 4. 行为边界

- 页面不发起任何彩报网络请求。
- 不提供刷新、日期切换、翻页、缩放、收藏、分享、下载、购买或外链操作。
- 不展示专家荐号、中奖承诺或预测性文案。
- 替换为真实彩报前，必须重新确认内容来源、版权授权、更新方式和异常状态。

## 5. 状态与无障碍

V1 图片随 APK 打包，因此正常情况下只有内容态。若资源解码失败，页面仍显示标题、静态说明和来源文字，不影响其他入口。

- 图片提供语义描述“彩报静态占位图：桌面上的报纸”。
- 说明文字不只依赖颜色表达。
- 系统字体放大时内容可纵向滚动，不截断关键信息。
- 深浅色主题下维持文本对比度。

## 6. 验收

- 底部能看到并切换五个入口。
- 彩报页在飞行模式下完整显示。
- 抓包或日志确认进入彩报页不会触发网络请求。
- 页面不存在刷新、翻页、收藏、分享、购买和荐号操作。
- API 26 与 API 37 模拟器上可打开，TalkBack 能读出标题、说明和图片语义。
