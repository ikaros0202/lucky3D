# Lucky3D 试机号与彩报联网设计

> 状态：V1.2 走势图历史试机号与彩报换期实施设计
> 日期：2026-08-02
> 适用版本：Lucky3D V1.2
> 视觉规格：`docs/design-spec.md`

## 1. 目标与边界

本设计在已确认的五页面 UI 重构中增加两项受控联网能力：

1. 首页展示彩经网当天发布的福彩 3D 模拟试机号，走势图按期读取彩经网历史试机号。
2. 彩报页读取牛彩网 A11“彩吧彩报第三版”，支持最近30个自然日期号切换，下载后保存在应用私有目录，离线打开时不重复加载。

继续遵守以下边界：

- Lucky3D 仍是数据分析与阅读工具，不提供购彩、支付、代购、兑奖或必中承诺。
- 试机号不是正式开奖结果，不写入 `draws` 表，不参与官方开奖同步、筛选结果或回测结算。
- 不建设自有服务端，不使用开发者个人电脑做代理。
- 不反向调用站点声明禁止抓取的私有 `/api/` 路径。
- 不把牛彩网图片打包进 APK；公开发布完整图片展示前必须确认展示授权。

- `m.cjcp.cn/robots.txt` 没有禁止不带查询参数的 `/kjhsjh/3dls/`，但禁止通配查询参数路径；V1.1 只读取第一页，不抓分页。

彩经网模拟试机号

### 2.2 牛彩网彩报

## 3. 推荐架构

采用“公开页面适配器 + Room 元数据 + 应用私有文件”的离线优先结构。

```text
公开 HTML 页面
  → OkHttp 获取
  → 站点专用解析器
  → 结构与业务校验
  → Repository 协调
  → Room 元数据 + 私有文件
  → ViewModel StateFlow
  → Compose 页面
```

每个单元只承担一个职责：

- `CjcpTrialDataSource`：下载彩经网页面，不接触 Room 或界面。
- `CjcpTrialHtmlParser`：把 HTML 转换为候选试机号。
- `Cz89CaibaoDataSource`：下载 A11 页面和经过批准的图片地址。
- `Cz89CaibaoHtmlParser`：解析期号、标题和图片 URL。
- `LiveContentRepository`：执行刷新策略、校验、缓存、清理和失败降级。
- `LiveContentDao`：Room 中最新试机号和彩报元数据的唯一读写入口。
- `CaibaoFileStore`：原子保存、读取和删除应用私有图片。
- Home 与 Caibao ViewModel：只依赖 Repository，不解析 HTML，不直接访问文件和 DAO。

不新增通用爬虫框架，不聚合其他彩种、文章或图库栏目。

## 4. 数据契约

### 4.1 试机号

```kotlin
data class TrialNumber(
    val issue: String,
    val number: String,
    val source: TrialSource,
    val sourcePageUrl: String,
    val sourceLocalDate: LocalDate,
    val fetchedAtEpochMillis: Long,
)

enum class TrialSource {
    CJCP_SIMULATED,
}
```

Room 表 `trial_numbers` 按 `issue` 保留最近成功记录；首页使用最新合格记录，走势图使用可见期号集合：

- `issue`：七位数字，例如 `2026201`。
- `number`：恰好三位数字，保留前导零。
- `source`：固定 `CJCP_SIMULATED`。
- `sourcePageUrl`：对应彩经网公开历史页或分页页面。
- `sourceLocalDate`：北京时间下本次成功刷新日期。
- `fetchedAtEpochMillis`：成功写库时间。

每条新记录只有在以下条件全部成立时才能写入或更新同一期旧记录：

- 期号匹配 `20\d{5}`。
- 号码匹配 `\d{3}`。
- 历史记录允许小于当前官方最新期号；首页今日试机号仍额外要求期号属于当前刷新目标。
- 页面中同时存在“模拟数据”或等价来源说明。
- 页面表头唯一、记录结构完整且没有重复期号或字段冲突；分页请求整页失败时不得写入该页。

彩经网历史页最多读取 `?page=1` 至 `?page=5`，只为当前走势图窗口补齐缺失期号；100期窗口最多读取五页，不保存超过需要范围的记录。

### 4.2 彩报

```kotlin
data class CaibaoDocument(
    val issue: String,
    val edition: String,
    val title: String,
    val sourcePageUrl: String,
    val imageUrl: String,
    val localFileName: String,
    val sha256: String,
    val mimeType: String,
    val width: Int,
    val height: Int,
    val cachedLocalDate: LocalDate,
    val fetchedAtEpochMillis: Long,
)
```

Room 表 `caibao_documents` 保存最近30个北京时间自然日内的缓存元数据，并支持按期号读取。约束：

- `edition` 固定为 `A11`。
- 期号必须匹配 `20\d{5}`。
- 页面标题必须包含“彩吧彩报第三版”。
- 页面地址必须是 `https://m.cz89.com/tuku/A11.htm` 或经过期号校验的 `https://m.cz89.com/tuku/A11-{issue}.htm`。
- 图片协议必须是 HTTPS，主机必须严格等于 `tuku.cz89.com`。
- 图片路径必须以 `/ftp/app/{issue}/A11.jpg` 或 `/ftp/yuwang/{issue}/A11.jpg` 结尾，且路径中的期号必须与页面期号一致。
- 响应类型只接受 JPEG 或 PNG。
- 最大下载大小为 8 MiB。
- 图片必须能够完成边界解码，宽高均大于零。

## 5. 试机号请求时机

统一使用 `Asia/Shanghai` 判断日期和发布时间。

彩经网说明其模拟试机号在开奖日约 16:30 发布。为避免在站点更新时间边缘重复请求，自动刷新窗口从 **16:35** 开始。

### 5.1 自动请求触发

只有以下事件可以触发资格检查：

- 应用进程启动。
- 应用从后台回到前台。
- 首页 ViewModel 首次开始收集状态。
- 应用在首页持续前台运行并跨过当天 16:35。

资格检查不会必然发起网络请求。必须同时满足：

1. 当前北京时间不早于 16:35。
2. 当天尚未成功取得新的合格试机号。
3. 当前没有相同刷新任务正在运行。
4. 当前时间已经超过 `nextEligibleAttempt`。
5. 当天自动尝试次数少于三次。

### 5.2 成功、旧数据与失败

- 成功取得当天新期号：当天不再自动请求。
- 页面仍是旧期号：保留本地数据，30 分钟后才允许下一次前台触发重试。
- 网络或解析失败：保留本地数据，30 分钟后才允许下一次前台触发重试。
- 当天最多三次自动尝试，避免每次进入首页都请求。
- 用户主动点击“刷新”可以立即触发一次，但并发请求会合并；手动失败不会删除本地数据。
- 16:35 前不自动联网，只显示最近缓存以及“今日数据预计 16:30 后发布”。

这一策略不使用 WorkManager、AlarmManager、后台服务或常驻轮询。

## 6. 彩报请求、缓存与清理

### 6.1 请求时机

- 首次进入彩报页时执行资格检查。
- 当天已成功检查过 A11 页面时，后续进入不再自动请求。
- 当天页面仍是旧期号或请求失败时，下一次自动检查至少间隔两小时，每天最多三次。
- 用户手动刷新不受“两小时”限制，但不允许并发下载。
- 如果 A11 页面指向的期号和本地最新记录一致，只更新检查时间，不重复下载图片。

### 6.2 文件缓存

图片保存到应用私有持久目录：

```text
filesDir/live-content/caibao/{issue}-A11-{sha256-prefix}.jpg
```

不使用 `cacheDir`，因为系统可以随时清理缓存目录，无法满足“下一次打开不重新加载”。

写入顺序：

1. 下载到同目录临时文件。
2. 校验大小、MIME、图片宽高和 SHA-256。
3. 原子重命名为最终文件。
4. 在 Room 事务中写入元数据。
5. 如果 Room 写入失败，删除本次新增最终文件。
6. 启动时清理遗留临时文件和没有 Room 元数据的孤儿文件。

### 6.3 三十天保留与按期切换

界面提供最近30个北京时间自然日内的有效期号选择，不预下载未选择的历史图片。

以北京时间 `cachedLocalDate` 为准，保留 `today.minusDays(29)` 至 `today`。早于 `today - 29 days` 的图片和 Room 元数据都删除。清理发生在：

- 应用进程启动；
- 进入彩报页；
- 彩报刷新成功后。

离线时优先显示当前选择期号的30天内缓存；选择期号超过窗口或没有缓存时显示过期/缺失状态和重试入口。

## 7. Room 与迁移

数据库从版本 3 升级到版本 4，新增：

- `trial_numbers`
- `live_content_refresh_metadata`
- `caibao_documents`

`live_content_refresh_metadata` 按 `contentType` 保存：

- 最近尝试时间；
- 最近成功时间；
- 最近成功的北京时间日期；
- 当天自动尝试次数；
- 下次允许自动尝试时间；
- 最近失败类型。

V1.1 使用三个逻辑行：

- `TRIAL_NUMBER`：只保存试机号刷新策略和刷新结果。
- `CAIBAO`：只保存彩报页面/图片刷新策略和刷新结果。
- `CAIBAO_CLEANUP`：内部清理错误作用域，只持久化彩报文件/Room 清理的
  `lastFailure`。它不传入 `RefreshPolicy`，不记录或消耗刷新次数，不设置冷却，也不代表
  彩报远端刷新成功或失败。

`CAIBAO_CLEANUP` 复用现有以文本 `contentType` 为主键的 metadata 表，不增加表或字段。
成功清理只清除该行的 `lastFailure`；彩报刷新只读写 `CAIBAO` 行，两者不能互相覆盖。

迁移必须是增量迁移 `MIGRATION_3_4`，不得使用 destructive migration。预置数据库仍作为初始安装来源；构建时同步生成并验证 Room v4 schema。

## 8. 错误模型与降级

跨层错误使用稳定枚举，不把异常文本传给界面：

```kotlin
enum class LiveContentFailure {
    NETWORK,
    HTTP,
    EMPTY_RESPONSE,
    INVALID_HTML,
    INVALID_ISSUE,
    INVALID_NUMBER,
    UNAPPROVED_IMAGE_HOST,
    IMAGE_TOO_LARGE,
    INVALID_IMAGE,
    FILE_IO,
    DATABASE,
}
```

界面状态规则：

- 有缓存 + 刷新失败：继续显示缓存，附“更新失败”和最后成功时间。
- 无缓存 + 刷新失败：显示明确错误、来源和重试按钮。
- 试机号是旧日期：显示日期与“非今日数据”，不伪装成当天内容。
- 彩报下载中：保留旧图并显示非阻塞进度；没有旧图时显示固定比例占位区。
- 解析结构变化：拒绝写库并记录 `INVALID_HTML`，不猜测号码或图片地址。

彩报刷新状态由 Repository 稳定合并三类来源，优先级固定为：
运行时状态 > `CAIBAO` 刷新失败 > `CAIBAO_CLEANUP` 清理失败 > `Idle`。因此进程重建后
成功清理可以清除持久化清理错误，同时不会误清或遮蔽真实彩报刷新错误。

## 9. 页面集成

### 9.1 首页

在柔光晶体首页的常用信息区加入紧凑试机号模块：

- 三位号码使用紧凑哑光小球，不与正式开奖号的大红球混淆。
- 明确展示来源“彩经网模拟”。
- 展示对应期号、数据日期和最后更新时间。
- 16:35 前、加载、有缓存失败、无缓存失败、旧数据五种状态都有明确文案。
- 自动刷新不显示打断式加载；手动刷新显示按钮进度。

### 9.2 彩报页

继续采用流动朱砂风格：

- 顶部显示 A11、完整期号、来源和缓存状态。
- 主体是可双指缩放、双击复位的本地图片阅读区。
- 图片始终从本地文件显示，网络成功后切换到新文件。
- 提供上一期、当前期号选择和下一期；无网时直接显示当前选择期号的30天内缓存。
- 不提供分享、导出、购买、收藏或其他图库入口。
- 底部提供来源页入口和版权说明。

## 10. 测试策略

### 10.1 纯单元测试

- 彩经网真实脱敏 HTML fixture 能解析 `issue` 和三位号码。
- `007` 保留前导零。
- 缺失字段、重复首行、非法期号、非法号码、旧期号均被拒绝。
- 牛彩网 fixture 能解析 A11 期号与图片 URL。
- 非 HTTPS、错误主机、错误路径、非 A11 标题均被拒绝。
- 16:34 不请求，16:35 首次请求。
- 当天成功后不再自动请求。
- 失败后 30 分钟冷却，当天最多三次自动尝试。
- 彩报相同期号不重复下载。
- 试机号分页返回多期记录，`007` 保留前导零，重复期号或页结构冲突整页拒绝。
- 彩报指定期号页面必须返回同一期 A11；不允许错误栏目、主机、路径或图片期号。
- 30天边界精确保留 `today.minusDays(29)`，删除前一天；按期选择器不显示窗口外期号。

### 10.2 集成测试

- MockWebServer 验证页面、图片、超限、错误 MIME、截断图片和超时。
- Room v3 → v4 迁移保留开奖、方案和复盘数据。
- 文件成功但数据库失败时不残留新文件。
- 删除过期元数据时同步删除对应文件。
- Repository 的 Flow 在失败时仍发出旧缓存。

### 10.3 Compose 与设备验收

- 首页在 16:35 前、成功、旧缓存、无缓存错误下层级清楚。
- TalkBack 会读出“彩经网模拟试机号”、期号、三个数字和非正式开奖提示。
- 彩报加载、30天按期缓存、上一期/下一期、过期、错误和缩放状态可操作。
- 320dp、393dp、横屏、1.3 倍字体、深浅色均无裁切。
- 切换首页与彩报页不会重复发起已不具备资格的请求。

## 12. 明确不做

- 不抓取彩经网推荐、关注码、金码、杀码或专家文章。
- 不保存试机号历史列表。
- 不抓取牛彩网 A11 之外的图库。
- 不后台定时唤醒设备。
- 不绕过验证码、登录、WAF、访问控制或 robots 禁止路径。
- 不把第三方图片提交到 Git 或打包进 APK。
- 不在未确认展示授权时把完整牛彩网彩报作为公开发行版的默认开启能力。
