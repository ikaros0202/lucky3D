# Lucky3D V1.2 走势缩放、试机号历史与彩报换期规格

> 状态：已实现并完成 V1.2 阶段验收
>
> Android 版本：`versionName 1.2.0` / `versionCode 2`
>
> 日期：2026-08-03
>
> 用户当前决定优先于 V1.1 原型和既有文档；确认后同步修改 PRD、数据设计、技术设计、设计规格和任务清单。

## 0. 已确认决策

1. 当前产品里程碑为 **V1.2**，对应 Android `versionName 1.2.0` / `versionCode 2`；V1.1 未单独形成安装版本。
2. 走势图左侧固定栏只保留“期号”，不再固定显示“开奖号”；基准宽度由当前窄屏 `108dp` / 常规屏 `122dp` 收窄为约 `72dp` / `80dp`。
3. 走势图右侧完整顺序固定为：

   ```text
   试机号 → 开奖号 → 百位0—9 → 十位0—9 → 个位0—9
   → 和值 → 和尾 → 跨度 → 奇偶比 → 大小比 → 012路个数比
   ```

4. 期数提供 `10 / 30 / 60 / 100`，默认仍为 30 期；统计和表格使用同一窗口。
5. 走势图不显示“全览”“100%”“缩小”或“放大”等按钮，只使用双指缩放；最小比例动态计算为“全览”，在目标窄屏上能同时看到从固定期号到最右侧 `012路个数比` 的全部列，最大比例为 `250%`。内容未触边时缩放以双指位置为中心；触边时夹紧偏移，禁止暴露大面积空白。固定栏、表头、表体、字号、行高、落点和连线保持同一缩放比例。期数选择按钮移入红色标题栏，与“走势”并排并保持固定尺寸。
6. 彩报换期采用“上一期 / 当前期号选择 / 下一期”；当前期号本身是唯一的期号菜单按钮，尺寸不小于 `48dp` 且视觉权重高于相邻文字操作。菜单按期号倒序包含窗口内全部有效期号，可见高度最多容纳 6 项并可纵向滑动。选择已有缓存时立即离线显示，选择未缓存期号时才访问牛彩网对应 A11 页面。彩报缓存保留 30 个北京时间自然日，删除窗口以前的图片和元数据。只支持已确认的 A11 彩吧彩报第三版，不扩展其他栏目。

## 1. 目标

V1.2 解决两个真实使用问题：

- 走势图列数增加后，用户既能缩小查看完整结构，也能放大读取单元格细节；期号始终可对照。
- 走势图按期展示来自彩经网的模拟试机号并缓存；彩报不再局限于最新一张，可在相邻期号间切换并复用本地缓存。

成功结果是：用户可以在同一张纵向长表里查看 10、30、60 或 100 期数据，缩放后不会丢列、错位或混淆期号；彩报换期不会伪造图片地址、不会用错误期号图片替代目标期号。

## 3. 走势图功能规格

### 3.1 表格结构

```text
┌──────┬──────────────────────────────────────────────────────────┐
│ 期数▼ │ 试机号 开奖号   百位0—9 十位0—9 个位0—9  和值 … 012路比 │
├──────┼──────────────────────────────────────────────────────────┤
│ 期号  │                  可缩放、可横向移动的完整数据区          │
├──────┼──────────────────────────────────────────────────────────┤
│2026201│  007    685       · · · ● …              19 … 1:0:2   │
│  …   │   …      …                    …                         │
└──────┴──────────────────────────────────────────────────────────┘
```

- 固定左栏：期号表头、每行完整七位期号、待开奖期号、统计行名称。
- 可缩放区：按用户指定顺序排列全部列。
- “百位 / 十位 / 个位”各自保留 `0—9` 十个数字子列、命中圆点、遗漏数字和组内连线。
- 试机号、开奖号均显示三位字符串并保留前导零；没有合格试机号时显示 `—`，不得拿开奖号或随机数补位。
- 属性列使用现有 `DrawAttributes` 口径：
  - 和值：`sum`
  - 和尾：`sumTail`
  - 跨度：`span`
  - 奇偶比：`oddCount:evenCount`
  - 大小比：`bigCount:smallCount`
  - 012 路个数比：`routeCounts[0]:routeCounts[1]:routeCounts[2]`
- 两期待开奖行继续保留；已取得对应试机号时可显示试机号，开奖号、号码落点和开奖属性保持空白。
- 四行统计继续位于表尾，只对百位、十位、个位的 30 个遗漏子列显示值；试机号、开奖号和附加属性列留空。

### 3.2 期数

- 选项固定为 `10 / 30 / 60 / 100`。
- 默认 30 期，切换时清除当前落点选择。
- 窗口内出现次数和冷热重新计算；同一期历史遗漏值不因窗口变化而重置。
- 100 期只创建当前 100 期、两期待开奖行和四行统计，不创建全部历史节点。

### 3.3 缩放与滚动

- 表格由一个占满可用内容区的统一 viewport 绘制和裁剪；手指位于固定栏或右侧数据区时，单指纵向滑动都更新同一个 viewport 纵向偏移，不再依赖外层页面异步滚动。
- 页面不显示“纵向连续浏览期次……”手势说明行，也不额外显示一整行“试机号、开奖号、百位……”列名说明；表头本身承担结构表达。
- 表头、表体、未来行和统计行共享同一个水平偏移与缩放比例，禁止分别计算导致错位。
- 缩放比例：

  ```kotlin
  val fitScale = minOf(1f, availableWidthPx / logicalTableWidthPx)
  val appliedScale = requestedScale.coerceIn(fitScale, 2.5f)
  ```

- `fitScale` 必须使用实际可用宽度和全部逻辑列宽计算，不写死某台模拟器的比例。
- 双指手势只负责整体缩放。每次手势从实际 viewport 建立初始状态，此后的事件使用上一事件累积得到的比例和偏移，并结合上一帧质心、质心平移量和相对缩放倍率，在同一次指针事件内原子更新比例、横向偏移和纵向偏移；不得在每个事件中重新读取尚未完成重组或布局的 ViewModel 状态，也不得通过异步滚动补偿。内容未触边时质心下的同一逻辑数据位置保持不变；触边时偏移夹紧为 `0—maxOffset`，优先保证内容覆盖视口，不允许负偏移或末端越界。单指水平拖动查看右侧列，单指纵向拖动更新同一 viewport 的纵向偏移。
- 不提供任何可见缩放按钮。缩放比例由双指手势连续改变，并限制在 `fitScale—2.5f`。
- 在 `fitScale` 下所有列同时可见，允许文字变小作为结构总览；放大后恢复精确读数。固定期号栏、各级表头、表体、未来行、统计行、文字、落点和连线全部使用同一比例，不能只改变右侧列宽；期数选择器位于标题栏，按钮、文字和箭头保持固定尺寸。
- 固定期号栏不参与水平移动，但其宽度、字号、行高和纵向位置必须与右侧共享同一缩放比例和行坐标。

### 3.4 试机号历史抓取与缓存

- 页面先从 Room 按可见期号集合读取试机号，缓存命中立即展示。
- 缺失时请求彩经网分页历史；最多读取满足当前窗口所需的页面，100 期上限为 5 页。
- 每页必须完成来源声明、表头唯一性、期号格式、三位号码、重复期号和载荷大小校验；整页无效则该页不写库。
- 合格记录在单个 Room 事务中批量 Upsert，不再执行 `DELETE FROM trial_numbers`。
- 历史试机号允许期号小于等于最新官方开奖期号；只有“首页今日试机号”仍执行当前期新鲜度判断。
- 网络、解析或数据库失败时保留已有缓存；缺失单元格显示 `—`，走势图其他数据继续可用。
- 试机号不写入 `draws`，不参与遗漏、冷热、筛选、回测或复盘。

## 4. 彩报功能规格

### 4.1 换期交互

```text
┌──────────────────────────────┐
│ 彩报                  [刷新] │
│ [上一期] [ 2026204 ▼ ] [下一期] │
├──────────────────────────────┤
│                              │
│       可缩放的 A11 图片       │
│                              │
└──────────────────────────────┘
```

- 默认选择远端最新期号；已有最新缓存时先显示缓存，再按现有刷新规则检查。
- “上一期 / 下一期”按已知有效期号序列移动，不使用简单整数加减跨越年度边界。
- 当前期号本身使用较大的按钮呈现并打开紧凑选择器，不另设“切换期号”按钮；标题区域必须避开状态栏、刘海和挖孔安全区。
- 候选来源为北京时间今天及此前 29 个自然日内，本地开奖记录、当前远端期号和已有彩报缓存中能够确认的有效期号去重并集；菜单包含全部有效期号，可见高度最多容纳 6 项，用户可在弹层内纵向滑动。
- 期号选择器按期号倒序显示，不能查询或选择 30 天窗口以前的期号；没有开奖或没有合法 A11 期号的自然日不生成虚假选项。
- 选择缓存期号：直接读取并校验本地文件，不联网。
- 选择未缓存期号：请求该期 A11 页面，解析页面真实图片地址，再下载、校验、写入私有目录和 Room。
- 请求返回期号与选择期号不一致时拒绝写入；失败时继续显示当前选择期已有缓存，否则显示该期错误状态和重试入口。
- 不预下载 100 期图片；只有用户明确选择的期号才下载。

### 4.2 图片缩放

- 保留现有双指缩放、拖动和双击复位。
- 缩放范围保持 `1x—5x`；切换期号后重置为 `1x` 和零偏移。
- 图片手势只在图片区域生效；未放大时页面纵向滚动优先，放大后图片拖动不触发换期。
- 解码失败必须使当前文档失效并保留其他期号缓存，不得误删全部缓存。

### 4.3 缓存与边界

- 继续使用 `filesDir/live-content/caibao/`，图片不得进入 Git、APK 或公共相册。
- 缓存窗口改为 30 个北京时间自然日：保留 `today.minusDays(29)` 至 `today` 的图片和 Room 元数据，删除 `cachedLocalDate < today.minusDays(29)` 的记录与对应私有文件。
- 清理在进入彩报页、成功缓存新图片后和应用现有清理触发点执行；边界日 `today.minusDays(29)` 必须保留，前一天必须删除。
- 历史期号在窗口内被用户读取并成功缓存后，可在其缓存日期仍处于 30 天窗口时离线再次打开。
- 只允许牛彩网 A11，禁止抓取 A11 之外栏目、绕过访问控制或根据期号直接猜测图片 URL。
- 完整图片公开发布仍以来源展示授权确认为门禁。

## 5. 状态与无障碍

- 走势：加载、正常、试机号部分缺失、试机号刷新失败、无开奖数据五种状态。
- 彩报：最新缓存、历史缓存、按期加载、按期无缓存错误、文件损坏、刷新失败但缓存可读六种状态。
- 所有按钮触控目标至少 `48dp`；走势图不能只靠红色表达命中，继续保留数字、圆点和文字语义。
- TalkBack 的每期摘要顺序与可见列顺序一致：期号、试机号、开奖号、三位数字、和值、和尾、跨度、奇偶比、大小比、012 路个数比。

### 6.3 代码风格

继续使用不可变 `UiState` 和单向数据流，例如：

```kotlin
data class TrendViewport(
    val requestedScale: Float = 1f,
    val fitScale: Float = 1f,
    val horizontalOffsetPx: Float = 0f,
)

fun setTrendScale(value: Float) {
    viewport.update { current ->
        current.copy(requestedScale = value.coerceIn(current.fitScale, 2.5f))
    }
}
```

页面不得直接读取 DAO、网络 DTO 或文件路径。

## 8. 边界

### 必须做

- Room 仍是界面唯一事实来源。
- 所有属性复用 `DrawAttributes` 和 `calculation-rules.md`，不在 UI 重写公式。
- 网络响应先校验、后事务写库；失败不清除已有内容。
- 使用真实开奖种子数据验证 100 期密度、缩放和性能。

### 需要先询问

- 扩展到 A11 之外的彩报栏目。
- 再次改变彩报 30 天缓存窗口或预下载历史图片。
- 改变第三方来源、公开发布授权门禁或自动请求频率。

### 禁止

- 伪造缺失试机号或彩报 URL。
- 把试机号当作官方开奖或用于筛选、回测、复盘。
- 新建云后端、代理服务、账号、购买、分享或推荐号码能力。
