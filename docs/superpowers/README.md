# `docs/superpowers` 历史目录说明

本目录保留 Lucky3D 已完成阶段的规格与实施计划，目录名来自当时使用的文档工作流，不代表当前本机仍安装 Superpowers Skill。

自 2026-08-12 起：

- 历史计划中原有的 `superpowers:subagent-driven-development` 和 `superpowers:executing-plans` 强制依赖已经退役；
- 继续阅读或复用历史计划时，以仓库根 `AGENTS.md`、`docs/codex-skill-inventory.md`、当前 `tasks/plan.md` 和 `tasks/todo.md` 为准；
- 不得根据历史计划自动安装、恢复或调用未在当前基线中列出的 Skill；
- `specs/` 中仍有效的产品、数据和交互结论，应按文档自己的替代关系与当前 PRD 判断，不能仅凭目录名推断状态。

保留原路径是为了避免破坏 PRD、设计规格、发布记录和任务文档中的历史链接。
