# Lucky3D V1.3 和值 0—27 连线走势图实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将走势图原单格“和值”替换为 0—27 遗漏连线图，并为每个和值展示出现次数、当前遗漏、平均遗漏和最大遗漏。

**Architecture:** 扩展现有 `OmissionCalculator`，通过显式合法值域让数字位置继续使用 `0..9`、和值使用 `0..27`。`TrendViewModel` 从 Room 提供的完整升序开奖记录预计算可见和值遗漏和全历史统计，Compose Canvas 只消费不可变状态并在现有统一 viewport 中绘制。

**Tech Stack:** Kotlin、Jetpack Compose Canvas、StateFlow、JUnit 4、Truth、Compose UI Test、Gradle Wrapper。

## Global Constraints

- 产品里程碑为 V1.3，最终 Android 版本固定为 `versionName 1.3.0` / `versionCode 3`。
- 和值合法范围固定为 `0..27`；百位、十位、个位继续固定为 `0..9`。
- 出现次数使用当前 10/30/60/100 期窗口；当前、平均、最大遗漏使用从 `2017001` 起的完整本地历史。
- 平均遗漏和最大遗漏只使用已经结束的遗漏段；没有已结束段时显示 `--`。
- 原单格和值属性列删除；和尾、跨度、奇偶比、大小比、012路个数比仍为普通文字列。
- 和值落点使用实心圆、白色数字和实线，不只依赖颜色表达命中。
- 值和统计由 ViewModel 预计算；Canvas 不在每帧遍历完整历史。
- 保持现有双指质心缩放、横纵拖动、固定期号栏和边界夹紧逻辑，不新增按钮、图例、筛选或点选详情。
- 不修改 Room Schema、DAO、网络 DTO、开奖/试机号/彩报来源，不引入新依赖。
- 本阶段只在本地提交，不推送 GitHub，不修改标签或 Release。

将 `OmissionCalculator` 的入口调整为：

```kotlin
fun calculate(values: List<Int>, target: Int): OmissionStatistics =
    calculate(values, target, 0..9)

fun calculate(
    values: List<Int>,
    target: Int,
    allowedRange: IntRange,
): OmissionStatistics {
    require(!allowedRange.isEmpty()) { "Allowed range must not be empty" }
    require(target in allowedRange) { "Target must be within allowed range" }

    var currentOmission = 0
    var previousHitIndex: Int? = null
    val omissionByDraw = ArrayList<Int>(values.size)
    val completed = mutableListOf<Int>()

    values.forEachIndexed { index, value ->
        require(value in allowedRange) { "History values must be within allowed range" }
        if (value == target) {
            previousHitIndex?.let { completed += index - it - 1 }
            previousHitIndex = index
            currentOmission = 0
        } else {
            currentOmission += 1
        }
        omissionByDraw += currentOmission
    }

    val average = completed
        .takeIf(List<Int>::isNotEmpty)
        ?.average()
        ?.let { round(it * 100.0) / 100.0 }

    return OmissionStatistics(
        omissionByDraw = omissionByDraw,
        completedOmissions = completed,
        currentOmission = currentOmission,
        averageOmission = average,
        maxOmission = completed.maxOrNull(),
    )
}

fun calculateVisibleWindow(
    values: List<Int>,
    target: Int,
    visibleWindowSize: Int,
): OmissionStatistics = calculateVisibleWindow(values, target, visibleWindowSize, 0..9)

fun calculateVisibleWindow(
    values: List<Int>,
    target: Int,
    visibleWindowSize: Int,
    allowedRange: IntRange,
): OmissionStatistics {
    require(visibleWindowSize > 0) { "Visible window must be positive" }
    val full = calculate(values, target, allowedRange)
    return full.copy(omissionByDraw = full.omissionByDraw.takeLast(visibleWindowSize))
}
```

在 `TrendChart.kt` 定义：

```kotlin
private const val TrendDigitCount = 30
private const val TrendSumCount = 28
private val TrendAttributeLabels = listOf("和尾", "跨度", "奇偶比", "大小比", "012路个数比")

internal fun calculateTrendLogicalRightWidth(
    prefixWidth: Float,
    cellWidth: Float,
    attributeWidth: Float,
): Float = prefixWidth * 2f +
    cellWidth * (TrendDigitCount + TrendSumCount) +
    attributeWidth * TrendAttributeLabels.size

internal fun calculateTrendValueCellCenterX(
    sum: Int,
    prefixWidth: Float,
    cellWidth: Float,
): Float {
    require(sum in 0..27) { "Sum must be between 0 and 27" }
    return prefixWidth * 2f + (TrendDigitCount + sum + 0.5f) * cellWidth
}
```

