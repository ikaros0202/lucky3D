# Lucky3D V1.1 UI 与实时内容实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现已确认的五个页面改版：首页采用“柔光晶体”，走势、选号、方案、彩报及二级页面采用“流动朱砂”；同时接入彩经网试机号与牛彩网 A11 彩报，在受控刷新、Room 元数据和应用私有文件缓存的约束下离线优先展示。

**Architecture:** 保留单 Activity、Navigation 3、不可变 `UiState`、Hilt 和 Room 唯一事实来源。新增独立的公开页面适配器、纯解析器、刷新策略、Room v4 元数据表和 `LiveContentRepository`；Home 与 Caibao 只消费 Repository 的领域模型。预置开奖数据库继续使用当前 v3 资产，首次打开由非破坏性 `MIGRATION_3_4` 升级。彩报图片写入 `filesDir/live-content/caibao`，先校验后原子提交，数据库失败时补偿删除。

**Tech Stack:** Kotlin 2.4.10, Jetpack Compose Material 3, Navigation 3, Room 3.0.0, OkHttp 5.4.0, kotlinx.serialization, Coroutines/StateFlow, Hilt 2.60.1, JUnit 4, Truth, MockWebServer, Compose UI Test, JDK 17, `minSdk 26`, `compileSdk 37`, `targetSdk 37`.

## Global Constraints

- 首页使用柔光晶体；走势、选号、方案、彩报、历史、设置、详情、弹窗使用流动朱砂。
- 品牌主色为朱砂红，橙色不作为品牌色；走势图内部不使用阴影。
- 一级入口固定为：首页、走势、选号、方案、彩报。
- Room 是运行时唯一事实来源；界面不接触 HTML、网络 DTO、DAO 或裸文件路径。
- 试机号是彩经网发布的模拟数据，必须明确标注来源与性质，不能伪装成官方开奖结果。
- 彩报只读取牛彩网 A11“彩吧彩报第三版”；不抓取其他版面、文章、彩种或分页。
- 不使用 WorkManager、AlarmManager、前台服务或常驻轮询。
- 不新增购彩、支付、代购、兑奖、AI 荐号、必中承诺、社区、分享、导出、账号、云端或其他彩种。
- 三位号码保留前导零；失败时保留最后成功缓存，不从空响应或异常内容推断数据。
- 所有触控目标至少 `48dp`；颜色不能是唯一状态编码；用户可见文案与辅助功能标签进入 `strings.xml`。
- 不提交下载的真实彩报图片，不修改或暂存用户的 `docs/design-concepts/`。
- 每个逻辑、迁移和行为改动遵循 RED → GREEN → REFACTOR；每个任务独立提交。
