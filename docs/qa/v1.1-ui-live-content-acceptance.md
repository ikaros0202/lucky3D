## 选号功能证据

- 默认进入普通单选，三个位置显示 `-`，不再把 1000 个单选号码作为默认结果。
- 数字输入按百位、十位、个位自动跳位；三位完成后自动加入“我的号码”，`007` 保持三位格式。
- 完成一组号码后回到百位，连续输入下一组时不会产生中间号码。
- 重复号码自动去重，并支持删除、清空、倍数、注数、金额和保存方案。
- 普通单选保存时不伪造筛选或胆拖条件；条件筛选、组选和胆拖保留在“更多选号方式”。
- 默认态和加入 `007` 后，目标期号、选号球、两行键盘、号码、金额和保存操作均在 API 26 单屏内可见。
- 未显示“从走势带入”“套用模板”等尚未接通真实链路的操作。

## 彩报功能证据

- 图片只从应用私有目录读取，不回退到网络 URL 直接展示。
- 读取时复验文件名、大小、SHA-256、MIME、签名、尺寸、结构和像素流。
- 文件缺失、元数据不一致或解码失败时删除失效记录并进入可重试状态。
- 有旧图而刷新失败时继续保留可阅读内容。
- 支持 `1f..4f` 双指缩放、平移和双击复位；配置变化恢复基础比例。
- 无缓存时显示加载或重试，不再显示“静态示意”“随应用安装”等开发说明。
- 下载的真实 A11 图片未进入 Git 或 APK；APK 只保留历史静态占位资源。
