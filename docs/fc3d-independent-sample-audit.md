# 福彩3D内置开奖独立抽样核验

> 核验日期：2026-07-28
> 被核验文件：`data/fc3d-seed.json`
> 数据范围：2017001—2026198，共3334期
> 结论：20期全部一致，未发现不一致

## 1. 核验方法

内置数据由福利彩票官网JSON查询接口生成。本次核验没有再次调用该接口，而是使用另一域名、另一数据呈现方式的逐期开奖HTML详情页：

- 独立核验来源：[3D之家历史开奖](https://www.3d178.cn/kaijiang/)
- 页面形式：每个期号一个HTML详情页
- 比对字段：期号、开奖日期、百位、十位、个位

抽样采用固定随机种子`20260728`，从2017—2026每年抽取2期，共20期。固定随机种子使抽样可以重复，按年份分层避免样本只集中在最近年份。

执行脚本：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\audit-fc3d-independent-sample.ps1
```

## 3. 同时执行的全量结构校验

`tools/validate-predevelopment-data.ps1`对全部3334期执行了以下检查：

- 期号唯一且严格升序。
- 每个自然年从首期到末期连续，无中间缺期。
- 每条记录恰好有三位0—9数字。
- 日期和期号格式合法。
- 文件声明数量等于实际数量。
- 计算规则黄金样例通过。

## 4. 结论与限制

本次结果支持“当前内置文件在抽到的20期中与独立历史页一致”，没有发现生成过程造成的号码或日期错误。

抽样不能从数学上证明全部3334期都正确。发布前仍应保留两道门槛：

1. 每次重新生成基线后，必须重跑全量结构校验和独立分层抽样。
2. 如任一独立来源与官方数据不一致，以福利彩票官方公告为准，并人工复核该期，而不是自动采用第三方结果。
