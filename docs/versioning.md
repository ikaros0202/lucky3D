## 规则

- 产品计划中的 `V主版本.次版本` 与 APK 的 `versionName` 对齐为 `主版本.次版本.修订号`。
- `versionCode` 每次形成新的可安装交付版本必须严格递增，不能复用旧值。
- 历史验收报告保留当时的版本号，不追改为当前版本。
- 当前版本以 `app/build.gradle.kts` 为构建事实来源；PRD、设计规格、任务计划和交付文件名必须与其一致。
