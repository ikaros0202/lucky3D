# Lucky3D 下一版本 UI 设计规格

> 由 `oiloil-ui-ux-guide` 设计流程整理。
> 状态：V1.4 既有页面行为与云南省开奖公告重排均已实现；本轮完成 API 37 全量设备测试、浅色首页和深色开奖详情复核，历史 V1.4 行为另有 API 26 证据；生产签名、物理真机、第三方彩报公开展示授权及选号/彩报最终设计验收另行关闭。
> Android 版本：`versionName 1.4.0` / `versionCode 4`
> 日期：2026-08-12
> 平台：Android 手机，Jetpack Compose + Material 3
> 设计语言：首页使用“柔光晶体”；走势、选号、方案、彩报及二级页面使用“流动朱砂”。

## 1. 设计方向

- **产品**：面向熟悉福彩 3D 基础走势的用户，提供开奖查看、走势分析、条件选号、方案保存和开奖复盘。
- **风格**：红色系、可信、克制、紧凑；保留彩票识别感，但不使用赌场霓虹、金币、中奖庆祝或制造焦虑的文案。
- **首页**：柔光晶体。以浅色晶体、柔和红光和少量冷色折射强调最新开奖结果。
- **其他页面**：流动朱砂。以暖白底、朱砂红标题与细流线形成稳定、清楚的工具感。
- **信息密度**：高密度但不拥挤。减少大卡片和无效留白，通过分区、细分隔线和字号层级组织内容。
- **核心原则**：最常用功能优先；高级能力按需展开；不删除当前 V1 已实现的真实能力。
- **语言**：简体中文。期号、三位号码和金额使用等宽数字，必须保留前导零。

### 1.1 确认稿还原门槛

确认稿不是抽象的风格灵感，而是实现和验收的主视觉基准。最终界面必须保持确认稿的：

- 页面层级、区块顺序和首屏信息密度；
- 主要容器轮廓、球体/图表/列表形态和装饰构图；
- 品牌色、背景纹理、边界、高光、阴影和图标语言；
- 主要字号比例、对齐关系与留白节奏。

允许调整的范围仅限：

- 由 Room 和 Repository 提供的真实期号、号码、指标、状态与时间；
- 用户可以理解并采取动作的简短加载、失败和恢复文案；
- 为 Compose、系统栏和深色模式所做的必要平台适配。

不得以“Material 3 平台适配”或“风格翻译”为理由，把确认稿简化成通用卡片、纯文本列表或另一套信息层级。
不得把抓取来源、检查时间、缓存机制、内部边界或其他项目背景放进面向用户的页面。
正常状态的全部核心内容必须按确认稿比例在一个手机屏幕内展示，不得依赖纵向滚动才能看到主要区块。

走势图交互确认稿是后续 Compose 实现和设计 QA 的首要交互基准；应直接打开完整独立
网页，不得使用缺少宿主样式的原始可视化片段。网页中的“柔光晶体”切换仅用于方案
对比，Android 走势图固定采用“流动朱砂”。走势图的字段、列顺序、布局、信息密度和
交互以该确认稿为最终基准；计算口径和数据来源仍按 `docs/calculation-rules.md` 与
`docs/data-source-and-sync.md` 实现。其他文档与确认稿冲突时，应修改文档，不扩展原型功能。

历史、设置、详情和弹窗若没有独立确认稿，必须复用对应主页面确认稿中已经确认的顶栏、
容器、按钮、列表、状态和装饰组件，不得另起一套通用 Material 视觉。

首页确认稿采用“图片视觉层 + Compose 数据层”的混合实现：晶面背景、开奖台、玻璃框架、
圆盘外壳、冷热轨道和首页态底部导航底座可使用随 APK 打包的静态图片资产；期号、日期、
开奖号码、属性值、遗漏值、试机号、同步状态以及所有交互和无障碍语义必须由 Compose 根据
`UiState` 实时绘制。禁止把带固定业务数字的整页截图作为运行时页面，禁止让装饰图片读取或
替代 Room 数据。1080×1920 是截图还原基准，其他窗口尺寸按相同锚点和比例适配。
1080×2400 长屏使用
`docs/design-concepts/v1.1-home-original-five/08-soft-light-crystal-runtime-content-tall.png`
作为仅供运行时适配的内容空壳，并继续复用同一底部导航切片；它不替代 06 确认稿，也不得
改变内容。长屏空壳中的冷态命中文案留空，由 Compose 与实时命中数共同绘制，避免生成图片
中的固定文案错误。两种比例都必须保持开奖球和位置圆盘为正圆，并使用同一 `UiState` 数据。
首页晶体空壳是固定浅色画布：即使系统处于深色模式，Compose 数据层也必须继续使用确认稿的
红、墨、蓝高对比颜色，并让状态栏采用深色图标，不得仅让代码文字切换成浅色。图片内固定
文案与代码数据必须保持相同光学字号；系统字体放大时，坐标型数据不突破预留空位，完整信息
仍通过 Compose semantics 提供给 TalkBack。

## 3. 字体

- **标题和正文**：Android 系统无衬线字体，避免额外字体包增加体积和中文字形缺失风险。
- **数字**：`FontFamily.Monospace`，用于期号、开奖号、遗漏值、注数、金额和走势图。
- **字重**：Regular 400、Medium 500、SemiBold 600、Bold 700。

### 字号层级

| 角色 | 字号 / 行高 |
| --- | --- |
| 页面标题 | `24sp / 32sp`，600 |
| 区块标题 | `18sp / 26sp`，600 |
| 正文 | `14sp / 21sp`，400 |
| 次级正文 | `13sp / 19sp`，400 |
| 标签 | `12sp / 17sp`，500 |
| 首页开奖球数字 | `40sp / 44sp`，700 |

## 4. 间距与密度

- 基础单位：`4dp`。
- 常用间距：`4 / 8 / 12 / 16 / 20 / 24 / 32dp`。
- 手机左右内容边距：普通页面 `16dp`；走势图表格为 `0dp`，工具栏为 `16dp`。
- 卡片内边距：常规 `16dp`；高密度列表 `12dp`；表格单元格横向 `6dp`。
- 区块间距：`16dp`；同组内容间距：`8dp`。
- 触控区域：Android 最小 `48 × 48dp`。
- 不为每一条信息创建独立大卡片；能用分隔线和背景分区表达的内容不增加外层卡片。

## 5. 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radiusSmall` | `8dp` | 标签、数字格、表格选中态 |
| `radiusMedium` | `12dp` | 输入框、次级按钮 |
| `radiusLarge` | `16dp` | 普通内容容器 |
| `radiusHero` | `24dp` | 首页开奖区、方案复盘头图 |
| `radiusFull` | `50%` | 彩票球和圆形命中点 |

表格、列表分组和底部导航不使用过度圆角。

## 6. 阴影和层级

- 流动朱砂页面主要通过背景色、边框和分隔线分层。
- 普通容器使用 `0–1dp` tonal elevation，不叠加厚重阴影。
- 底部浮动汇总条和对话框使用 `4–6dp` elevation。
- 首页晶体面板使用柔和的双层高光和 `2–4dp` 阴影；禁止逐个小卡片都加发光效果。
- 走势图内部不使用阴影，保证网格和数字清晰。

## 7. 动效

- 动效词汇：克制、快速、用于反馈。
- 按压反馈：`100–150ms`，使用 Material ripple 或透明度变化，不改变布局尺寸。
- 页面状态切换：`180–220ms`。
- 底部表单、详情面板：`240–280ms`。
- 开奖球数字切换允许短暂交叉淡化，不使用旋转、弹跳或中奖庆祝。
- 尊重系统“移除动画”设置；关闭后直接切换状态。

## 8. 容器、图标与装饰

### 8.1 容器策略

- 首页：`tinted-surface + low elevation`。
- 走势：`divider`，表格是一个连续整体。
- 选号：核心选号区使用单一浅朱砂背景，其他能力以分区和列表呈现。
- 方案：列表使用分组标题和分隔线；详情用少量容器。
- 彩报：图片是主内容，来源说明使用单独信息区。

### 8.2 图标系统

- 统一使用 Material Symbols / Material Icons Outlined。
- 导航图标 `24dp`；正文图标 `20dp`；空状态图标 `40dp`。
- 同一层级不混用粗细不同或填充与线框两套风格。
- 图标按钮必须有中文 `contentDescription`；装饰图标设为不可访问。

### 8.3 装饰策略

| 页面 | 渐变 | 纹理 | 图形动机 |
| --- | --- | --- | --- |
| 首页 | 柔和红白和少量淡紫 | 低对比晶面 | 晶体切面、圆形开奖台 |
| 走势 | 顶栏单一红色渐变 | 无 | 细朱砂流线，仅限标题区 |
| 选号 | 局部浅红渐变 | 极淡点阵，可关闭 | 哑光彩票球 |
| 方案 | 无或极弱渐变 | 无 | 标题区朱砂弧线 |
| 彩报 | 无 | 无 | 图片内容本身 |

装饰层不能影响文字对比度，不能进入走势图网格和表格数据区。

## 9. 通用组件约定

### 按钮

- 主按钮：朱砂红底、白字、`12dp` 圆角、高度至少 `48dp`。
- 次按钮：浅红容器、深红文字。
- 线框按钮：透明底、`outline` 边框。
- 纯图标按钮：可见图标 `24dp`，触控区 `48dp`。
- 禁用态：同时降低背景与文字强调，并提供不可点击语义。

### 输入和选择器

- 标签始终可见，不能只依赖 placeholder。
- 默认高度至少 `48dp`。
- 期号最多 7 位数字，倍数限制 `1–99`，错误显示在对应输入附近。
- 期数选择使用紧凑下拉选择器，不在页面额外占一整排按钮。

### 彩票球

- 首页使用柔光晶体球；选号和方案使用哑光朱砂球；走势图使用纯色命中圆点。
- 数字始终居中并占球体主要视觉面积。
- 未选择号码显示 `-`，不得显示空白、问号或浅灰数字。
- 球体的高光、阴影和边缘不能降低数字辨识度。

### 底部导航

- 固定五项：首页、走势、选号、方案、彩报。
- 高度包含系统导航栏安全区，单项触控区至少 `48dp`。
- 选中态同时使用红色、轻背景或指示条、文字字重变化，不能只改变图标颜色。
- 切换一级页面时保留各页面的主要滚动和选择状态。

## 10. 页面规格

### 10.1 首页：柔光晶体

#### 正常状态

1. 顶部显示 Lucky3D 品牌、刷新和设置。
2. 首页只保留一个开奖入口：当前期号按钮。开奖日期以次级文字显示，仅作元数据，不可点击、不可打开查询，也不与期号形成第二入口。
3. 点击期号进入开奖查询/详情页，默认选中当前期号；查询页只通过期号选择器切换记录。
4. 首屏核心是三个柔光红色开奖球，数字尽可能大。
5. 紧随其后展示和值、和尾、跨度、组选形态。
6. 第二层展示奇偶比、大小比、质合比、012 路和连号。
7. 展示“冷态命中”回顾：使用最新一期之前的 30 期计算位置数字冷热，明确显示位置、号码、此前遗漏和窗口，不使用“预测”。
8. 展示百位、十位、个位当前遗漏及简化冷热刻度，颜色之外同时显示数字和标签。
9. 展示紧凑“试机号”区域和三位号码；真实三位号码使用高对比红色并与标题形成清晰层级，`---` 保持弱化。取得后跨日持续显示到次日北京时间 `16:30`，到点后在当日新号成功写入前显示 `---`，刷新成功后替换为新号码；不展示来源、性质、检查时间、抓取时间或缓存机制。刷新与设置操作都使用同一套轮廓矢量图标加文字，图标与标签在各自晶体分栏内居中，父级触控目标至少 `48dp`。
10. 开奖球与位置分析之后展示云南省开奖公告摘要：标题固定为“云南省开奖公告”，金额字段只显示“销售额”；公告期号在标题右侧使用清晰、显著的字号并保留足够右侧内边距；三玩法中奖注数与单注奖金按单选→组三→组六排列。奖池资金余额不在首页展示，仅属于开奖详情页金额摘要。
11. 仅当存在正数派奖时在公告摘要末尾显示整行 `【派奖】`，按单选→组三→组六列出正数玩法及注数；没有正数派奖时整行不存在。
12. 展示同步状态、最后成功更新时间和重试入口。
13. 首页不再铺陈多条往期开奖；历史记录通过期号入口进入的查询/详情页查看。
14. 首页不展示胆拖内容。

#### 状态

- 加载：先显示本地最新结果，只在同步状态区显示进度。
- 空：阻止展示伪造分析，显示数据恢复说明和重试。
- 无网/失败：保留本地内容，顶部显示同步状态和重试。
- 数据修正：显示可关闭说明，并允许进入受影响期号。
- 待开奖：三个球显示 `-`，属性区域显示 `--`。

### 10.1A 开奖查询：期号入口与云南奖情内联

- 页面标题为“开奖查询”；首屏只放当前期号选择入口，触控目标至少 `48dp`。期号选择器按有效期号倒序列出记录，日期作为每行次级元数据，不可单独点击或筛选。
- 点击期号后，页面顺序固定为：开奖结果 → 云南省开奖公告 → 玩法奖情/派奖（如有） → 数据分析。结果、公告和分析直接嵌在页面内，不以底部弹层作为主要详情。
- 云南省开奖公告标题固定为“云南省开奖公告”，金额标签固定为“销售额”，并展示销售额、中奖总额、奖池资金余额、公告期号、开奖日期、兑奖截止日（有来源时）、三玩法中奖注数与单注奖金。销售额、中奖总额与奖池资金余额同属金额摘要，兑奖截止日作为独立日期字段；三玩法行顺序固定为单选→组三→组六。
- 奖池资金余额来源固定为云南接口 `prizeLog.nextAmount`；领域与 Room 以分（`Long`）保存，输入非负且最多两位小数，官方真实 `0` 与旧库 `null` 区分。列表与详情值不一致、非法或缺失时整条公告不入库，详情不使用其他来源补齐。
- 不显示“基础中奖”可见分组标题；三玩法行本身仍保留中奖注数和单注奖金。存在正数派奖时追加 `【派奖】` 行并按单选→组三→组六排序，没有正数派奖时整行不渲染。
- 公告字段必须来自独立且已校验的云南省奖情记录；缺失时显示明确缺失/不可用状态，不以其他地区、全国奖情、第三方文章或空响应补全。
- 详情只将公告与所选期号的开奖结果配对；跨期旧公告不得和最新开奖号拼接，期号不一致时公告区域显示缺失/不可用。
- 无记录状态保留期号入口并显示明确空态；不展示空公告或空分析卡片。旧期号、年份、最近期数和日期范围查询模型可为兼容保留，但不在当前 UI 暴露。

### 10.2 走势：流动朱砂

#### 表格结构

完整列顺序固定为：

```text
[统一缩放/横滑区域] 期号 → 试机号 → 开奖号 → 百位0—9 → 十位0—9 → 个位0—9
                    → 和值0—27 → 和尾 → 跨度 → 奇偶比 → 大小比 → 012路个数比
```

- 期号是统一内容第一列，不再构成固定左栏；横向拖动时可与试机号、开奖号和全部属性列一起移出视口。
- 表头、数据行、未来行和统计行共用同一个横向偏移和逻辑坐标；双指缩放状态同时作用于期号和其余全部尺寸，列顺序不得变化。
- 纵向使用连续长列表，不使用页码分页；全部表格内容在单一 viewport 内共享纵向偏移。
- 期数选择器位于红色标题栏内，与“走势”标题横向并排，提供 `10 / 30 / 60 / 100`；默认 30 期。控件保留 `48dp` 触控高度，视觉主体使用紧凑胶囊样式；文字和箭头不随表格缩放变化。
- 已开奖数据后固定保留两期未开奖空白行，开奖号以 `-` 表示，其他属性留空。
- 和值以`0—27`的 28 个子列进入右侧统一 viewport；实际和值使用圆点和实线连线，其余 27 格显示遗漏。
- 数据区后显示四行统计：出现次数、当前遗漏、平均遗漏、最大遗漏；统计覆盖每个位置数字及和值`0—27`。出现次数使用可见窗口，其余三项使用完整已确认历史，平均遗漏和最大遗漏只统计已结束遗漏段。
- 每 5 期使用稍强分隔线；最新一期使用浅红底；未开奖行使用斜纹并带文字语义。
- 命中点使用红色实心圆、白色数字和连线；遗漏数字始终可读，不能只靠颜色表达命中。
- 百位、十位、个位和和值`0—27`连续排列；和值之后的属性列依次显示和尾、跨度、奇偶比、大小比和012路个数比。

#### 交互与性能

- 使用一套共享横向滚动和变换状态，不为表头和表体创建可能失步的独立手势。
- 10期、30期、60期或100期直接绘制为连续表格；不得加载或创建全部历史期次节点。
- 不显示缩放按钮；双指缩放最小比例由可用宽度与包含期号在内的完整逻辑列宽计算，最小比例必须能同时看到全部列，最大比例为250%。一次手势内使用单一累积 viewport 原子更新比例和横纵偏移，不得逐帧重新读取尚未完成布局的外部状态。内容未触边时以双指位置为中心；触及上下左右内容边界时将偏移夹紧到可覆盖视口的范围，禁止缩小再放大后残留大面积空白。期号、其余表头、表体、字号、行高、落点和连线按同一比例整体变化。
- 单指横向拖动移动包括期号在内的整张表；从任意列开始单指纵向拖动都更新同一个 viewport 纵向偏移。页面不额外显示手势说明行或重复列名说明行。
- 走势图下方不显示“当前点位”、期号、开奖号、位置或遗漏详情摘要条；页面空间优先留给表格本身。
- TalkBack 提供整表摘要，并为每期提供可读的合并描述。
- 字体放大时保持表格列宽，通过缩放和横滑查看，不裁掉末列；期号与其余列的行高始终对齐。

### 10.3 选号：流动朱砂

#### 默认普通单选

1. 顶部显示目标期号按钮、页面标题和清空操作。
2. 默认进入“普通单选”，这是页面最显眼、最先可操作的区域。
3. 使用百位、十位、个位三个大号哑光球；未选择显示 `-`。
4. 当前正在选择的位置有清楚的描边和文字，不只用颜色表示。
5. 数字键盘 `0—9` 采用两行布局；选择后自动移动到下一位。
6. 三位齐全后“加入方案”可用；加入后出现在“我的号码”列表并保持三位格式。
7. 重复号码不重复加入，并给出可理解反馈。

#### 更多选号方式

- 组选 3、组选 6、胆拖、条件筛选放在“更多选号方式”区域，默认不展开复杂编辑器。
- 保留当前 V1 已实现的条件筛选、排除数量、冲突解释、撤销、倍数、注数、金额、保存模板和保存方案。
- “从走势带入”和“套用模板”只有在真实导航和数据恢复链路接通后才显示为可用操作；禁止放置无行为按钮。
- 页面底部使用固定或随内容出现的汇总条：注数、倍数、金额和保存方案。
- 金额旁持续显示“仅用于方案核对”，没有支付或下单入口。

#### 状态

- 无候选：保留所有条件，显示冲突原因和撤销入口。
- 保存中/成功/失败：按钮与就近状态完整闭环。
- 空“我的号码”：用一句简短提示，不增加大面积空卡。

### 10.4 方案：流动朱砂

- 顶部使用“方案 / 模板”分段选择，数量显示在标签内。
- 方案页提供搜索和“全部 / 待开奖 / 已复盘”筛选。
- 待开奖和历史复盘分组展示；列表使用分隔线，不把每条方案做成大卡片。
- 方案行显示期号、标题、玩法、注数、金额、候选数和状态。
- 已复盘方案直接显示“包含开奖号 / 未包含开奖号”，同时显示开奖号球，不能只用红绿。
- 模板页按常用和全部分组，提供历史回测与套用到本期。
- 方案详情头部展示期号、玩法、标题、开奖号球和复盘结果；下方展示注数、倍数、金额、候选号码、筛选条件、备注。
- 已开奖方案不可覆盖，底部主操作为“复制到本期”；文案明确修改将创建副本。
- 空方案页提供“开始选号”；空模板页说明模板用途并提供创建路径。

### 10.5 彩报：流动朱砂

- 当日在线检查后缓存，后续离线读取；顶栏显示 Lucky3D、彩报和缓存/错误状态。
- 主标题行显示“彩报 A11第三版”；`A11第三版` 与“彩报”同行，使用小字号和浅色次要文本。来源仍固定为牛彩网 A11 彩吧彩报第三版，但不在页面增加抓取或缓存机制说明。
- 标题区域避开状态栏、刘海和挖孔安全区；主内容显示当前选择期号的本地图片。
- 期号同行从左到右紧邻显示较大的当前期号按钮、上一期、下一期；当前期号是唯一的菜单入口，不另设“切换期号”按钮。最早有效期号禁用上一期，最新有效期号禁用下一期；禁用状态同时具备不可点击语义和浅色视觉。三个触控目标均不小于 `48dp`。菜单按期号倒序包含窗口内全部有效期号，可见高度最多容纳6项，用户可纵向滑动查找其他期号。缓存命中不联网，未缓存才请求对应 A11 页面。
- 支持双指缩放、拖动、双击复位和纵向滚动；缩放手势只作用于图片区域，不与系统返回和页面纵向滚动冲突；切换期号后缩放与偏移复位。
- 图片下显示“内容版权归原网站及原作者所有”及公开发布前需确认展示授权的说明。
- 无缓存、过期、下载或解码失败时显示来源说明、错误状态和重试入口，不显示空白页。

## 11. 数据与架构约束

- Room 继续是运行时唯一事实来源；UI 重构不得让页面直接读取网络 DTO。
- 不修改福彩 3D 计算公式或规则版本；V1.1 按已确认设计通过 Room v4 增加实时内容元数据，页面不直接读取网络 DTO。
- 首页新增的和值、和尾、跨度、比例、012 路和冷态命中全部由现有本地开奖记录计算。
- 开奖号码同步与云南省开奖公告分离；公告只读取按期号关联、已校验的云南奖情记录。既有开奖同步响应中的销售额不得直接作为公告卡片内容；首页只接收与最新开奖号同一期的公告，详情只接收与所选期号同一期的公告。
- 云南奖情字段缺失或修正时只更新公告状态/内容，不修改开奖号码；同一期公告的三玩法行按单选→组三→组六稳定排序，派奖行按正数玩法过滤。
- 奖池余额由 `prizeLog.nextAmount` 以非负、最多两位小数解析为分 `Long`；列表/详情不一致或非法/缺失不得写入 Room，历史 `null` 不得当作官方零值。
- “冷态命中”定义为：以最新期开奖前的 30 期为窗口，某位置本期命中数字在该窗口的活动比低于 `0.8`；同时展示此前当前遗漏。
- 试机号仅展示经 55125.cn 公开页面校验的数据，不把开奖号或随机数伪装成试机号；首页允许昨日合格记录跨日显示至北京时间 `16:30`，到点后今日记录尚未成功写入时显示 `---`，`16:30` 后用户主动刷新失败才显示“失败”。
- 走势图两期空白行只表示待开奖区域，不写入 Room，也不参与统计。
- 方案、模板、条件和滚动位置继续使用 ViewModel、持久层或可保存 UI 状态恢复。

## 12. 加载、错误、无网与成功状态

五个一级页面必须覆盖：

| 状态 | 表现 |
| --- | --- |
| 内容 | 展示真实本地数据 |
| 加载/同步 | 保留旧内容，局部显示进度 |
| 空 | 说明原因和下一步，不制造示例业务数据 |
| 无网 | 展示本地数据、上次更新时间和重试 |
| 错误 | 说明发生了什么以及如何恢复 |
| 成功 | 保存、复制、刷新等操作给出就近确认 |
| 数据修正 | 标识受影响期号，不静默替换用户理解 |

## 13. 页面适配

- 目标基线：确认稿对应的手机竖屏比例；正常状态全部核心内容必须在一个屏幕内展示。
- 横屏保持可操作，但不为本版本增加平板专用多栏信息架构。
- 所有触控目标至少 `48dp`。
- 本项目不实现或验收无障碍模式和系统字体缩放布局。
- 图表和状态保留清晰数字与标签。
- 浅色和深色模式独立检查。
- 底部导航、固定汇总条和吸顶表头必须避开系统栏，并为滚动内容预留内边距。

## 14. 本项目禁止项

- 不恢复首页多条往期开奖列表。
- 不使用橙色作为品牌主色。
- 不把所有小信息都做成大卡片。
- 走势图不得重新建立固定期号左栏；期号作为统一横向内容首列，与试机号、开奖号和属性列共同缩放和移动。
- 不把百位、十位、个位拆成三个无法同时浏览的分页。
- 不使用分页加载代替走势图纵向长页；期号选择只作用于彩报最近30个自然日窗口。
- 不使用玻璃拟态降低表格、选号数字或正文对比度。
- 不放置无真实行为的“从走势带入”“套用模板”等按钮。
- 不使用“预测、推荐号码、必中、提高中奖率”等措辞。
- 不新增在线购彩、支付、代购、分享、社区或云端能力；实时内容仅限已确认的 55125.cn 福彩 3D 试机号和牛彩网 A11 彩报，不扩展其他第三方栏目。
